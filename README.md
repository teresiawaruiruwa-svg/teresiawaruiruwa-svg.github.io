# Cybersecurity Portfolio — GitHub Pages build

This is a static HTML/CSS/JavaScript portfolio refresh based on the supplied Cyber Shujaa portfolio assignment report.

## Files
- `index.html` — single-page portfolio and content
- `assets/css/styles.css` — responsive styling
- `assets/js/main.js` — mobile navigation and current-year footer
- `screenshots/README.md` — six screenshot placement instructions

## Publish to GitHub Pages
1. Open repository settings for `teresiawaruiruwa-svg.github.io`.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment workflow to complete.
5. Open `https://teresiawaruiruwa-svg.github.io/` and verify the page.

## Before publishing
- Replace the portrait placeholder with a professional headshot at `assets/images/profile.jpg` and update the markup.
- Insert only redacted screenshots into the screenshot slots.
- Confirm employment dates, education dates, certification details, contact links, and public profile wording.
- Add URLs for lab write-ups and the featured article only after those pages are published.
- Do not publish lab flags, credentials, tokens, VPN/account identifiers, or sensitive target details.

## Design and implementation
Framework-free static site using semantic HTML5, CSS Grid/Flexbox, responsive breakpoints, accessible focus styles, reduced-motion support, and a small JavaScript enhancement for mobile navigation. Google Fonts are loaded remotely; system sans-serif fallbacks are provided.
